## Featured Projects

### FreshMart — Cloud-Native Grocery Platform
`ASP.NET Core` `Angular` `Redis` `RabbitMQ` `Docker`

A 12-service platform covering catalog, order lifecycle, and payments, with a LangChain-based agentic assistant using RAG. Built with an API gateway in front of stateless services, RabbitMQ for async messaging, Redis for caching and sessions, Razorpay for payments, and SignalR for real-time updates. Jenkins + Docker CI/CD with xUnit coverage across all services.

### MerchantRail — Payment Gateway
`Java` `Spring Boot` `Kafka` `PostgreSQL` `gRPC`

An 8-service payment gateway built with Hexagonal Architecture and a Kafka saga pattern for distributed transaction coordination — ISO 8583 bank authorization over gRPC, ISO 20022 SFTP settlement messaging, Redis-backed idempotency, and the outbox pattern. 85%+ test coverage across JUnit, Spock, and Testcontainers, with chaos testing via Toxiproxy and OWASP scans in CI.

### QuantForge — Algorithmic Trading Platform
`MERN` `BullMQ` `WebSocket`

A MERN-stack platform for generating and running algorithmic trading strategies, with LLM-assisted strategy generation, BullMQ job queues for execution, sandboxed strategy code, and real-time analytics over WebSocket.

### FinFlow — Loan Management Platform
`Spring Boot` `AWS` `Grafana`

A microservices loan management platform with Eureka service discovery, Spring Cloud Config, JWT-based auth and RBAC, RabbitMQ-driven async processing, and full observability via Prometheus, Grafana, and Zipkin.
