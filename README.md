## ⚡ About Me

I am a **Software Engineer** specializing in **Distributed Systems**, **High-Concurrency Backend Architecture**, and **Agentic Infrastructure**. My work centers on designing fault-tolerant pipelines, optimizing asynchronous task execution, and engineering developer tooling for the modern AI ecosystem (Model Context Protocol).

- 🔭 **Currently Building**: High-reliability tooling and bridges for AI agents, including Chrome DevTools MCP and distributed multi-agent systems.
- ⚙️ **Core Focus**: Distributed job queues, Redis internals & atomic Lua scripts, fault-tolerant orchestration, and high-throughput microservices.
- 🏆 **Problem Solving**: Active competitive programmer on [Codeforces](https://codeforces.com/profile/maheshsingh0905a), dedicated to algorithmic optimization, complexity reduction, and data structures.
- 💬 **Ask Me About**: Redis locking & queue stall detection, Model Context Protocol (MCP) server design, Node.js internals, and distributed state machines.
